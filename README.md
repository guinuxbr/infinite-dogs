A fast, responsive, and feature-packed web application for endless dog pictures and breed exploration powered by the
[Dog API](https://dog.ceo/dog-api/).

---

## ✨ Features

- 🐶 **Endless Dog Gallery**: Seamless infinite scrolling of adorable dog pictures from across the globe.
- 🐾 **Dynamic Breed Filtering**: Filter by any official breed or sub-breed
  (*Golden Retriever, Siberian Husky, Corgi, Pug, Beagle, Samoyed, etc.*).
- 🔍 **Live Breed Search**: Instant real-time filtering to quickly find your favourite dog breeds.
- 🖼️ **Full-screen Light box**: View high-resolution photos with full-screen zoom, keyboard navigation (`←`/`→`), and
  quick actions.
- ❤️ **Favourites & Bookmarks**: Save your favourite furry buddies locally in your browser with a dedicated manager
  modal.
- 📋 **One-Click Sharing & Copy**: Copy image URLs instantly or share with native mobile Web Share API.
- 📥 **One-Click Download**: Download high-resolution dog photos directly to your device.
- 🌙 **Dark & Light Mode**: Seamless theme switching with automatic system OS preference detection.
- 📐 **Customizable Layouts**: Switch between multi-column masonry grids and toggle automatic infinite scroll.
- ⌨️ **Keyboard Navigation**: Power-user shortcuts for fast, mouse-free browsing.
- 📲 **PWA & Offline Capable**: Installable as a progressive web app with Service Worker offline caching.
- 🚀 **Automated CI/CD**: Automatic deployment to GitHub Pages via GitHub Actions with pinned commit SHAs.

## ⌨️ Keyboard Shortcuts

| Key                              | Action                                              |
|:---------------------------------|:----------------------------------------------------|
| <kbd>Space</kbd> or <kbd>N</kbd> | Fetch more dog pictures                             |
| <kbd>/</kbd>                     | Focus breed search / filter box                     |
| <kbd>→</kbd> / <kbd>←</kbd>      | Next / Previous photo in Lightbox view              |
| <kbd>C</kbd>                     | Copy active photo URL to clipboard                  |
| <kbd>F</kbd>                     | Toggle Favorite or open Favorites manager           |
| <kbd>T</kbd>                     | Toggle Dark / Light theme mode                      |
| <kbd>?</kbd>                     | Open Keyboard Shortcuts guide                       |
| <kbd>Esc</kbd>                   | Close Lightbox / modals or clear search input       |

## 🛠️ Tech Stack

- **HTML5 & Modern Semantics** with ARIA accessibility compliance
- **CSS3 / Modern Variables & Glassmorphism** (responsive down to 320px, masonry columns, zero layout shift)
- **Vanilla JavaScript (ES6+)** with Fetch API, Web Share API, Clipboard API, and LocalStorage
- **Font Awesome 6** & **Google Fonts (Poppins)**
- **GitHub Actions** for automated CI/CD deployment
